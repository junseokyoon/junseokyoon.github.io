## GitHub Pages

GitHub에서 제공하는 무료 정적 사이트 호스팅 서비스입니다.

### 장점

- 무료
- [[Jekyll]] 자동 빌드
- 커스텀 도메인 지원
- HTTPS 지원

### 사용 방법

1. 저장소 생성 (`username.github.io`)
2. [[Jekyll]] 설정
3. 코드 push
4. 자동 배포
